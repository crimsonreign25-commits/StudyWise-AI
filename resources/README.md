# StudyWise Revision Resources

This folder is the starter location for the searchable revision library. It currently contains no actual past papers or notes. Add verified resource metadata to `index.json` or build a database-backed index.

Suggested metadata fields: `id`, `title`, `resourceType`, `curriculum`, `level`, `subject`, `topic`, `year`, `examBody`, `sourceName`, `sourceUrl`, `rights`, `verifiedAt`, `contentText` (only when authorized), and `tags`.

Resource types: `past-paper`, `marking-scheme`, `topical-questions`, `revision-notes`, `summary`, `presentation`, `syllabus`, `mock-paper`.

Use official/publicly released sources, licensed materials, or uploads for which the uploader has permission. If rights are unclear, keep metadata and a link rather than copying full text. Label AI-generated practice and trend-based revision priorities clearly; never promise exam predictions.
